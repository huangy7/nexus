# 📡 端口工坊 (Port Studio) Design Specification (方案 A)

## Overview

基于用户选择的 **方案 A：赛博雷达矩阵仪表盘 (Cyber Matrix Radar Dashboard)**，本文档定义 Nexus 端口工坊的架构、UI 布局、交互细节及 40+ 常用端口与服务协议全集。

---

## 1. 架构与 UI 布局

### 1.1 顶栏控制中枢 (Control Banner)
- **目标地址输入** (`#portInputHost`)：自动获取用户当前公网 IP，支持手动输入自定义 IP 或域名（如 `125.77.141.2`, `example.com`）。
- **常用场景 Pill 快速载入** (`.port-preset-pill`)：
  - `🌐 Web 基础服务 (80, 443, 8080, 8443, 3000, 5000, 8000)`
  - `🖥️ 远程运维 (22, 23, 3389, 21, 5900)`
  - `🗄️ 数据库集群 (3306, 5432, 6379, 27017, 1433, 1521, 9200)`
  - `📨 消息中间件 (5672, 15672, 9092, 2181, 8848)`
  - `🛡️ 高危安全暴露 (21, 23, 135, 445, 2375, 6379, 3389)`
  - `⚡ 全量热门扫描 (一键载入所有 40+ 热门端口)`
- **自定义端口输入** (`#portInputPorts`)：支持逗号分隔、端口范围或自由组合（如 `21, 22, 80-90, 3306`）。
- **操作按钮**：`📡 开始雷达扫描`、`📋 复制扫描结果`、`🧹 清空`。

### 1.2 主体：分类折叠网格与状态筛选 (Categorized Foldable Grid)
- **状态筛选器**：`全部端口 (All)` | `仅看开放 🟢 (Open Only)` | `仅看风险 🛡️ (High Risk)`。
- **5 大分类折叠卡片**：
  1. **Web 与应用框架服务** (80, 443, 8080, 8443, 3000, 5000, 8000, 8888, 9000)
  2. **远程连接与运维管理** (22, 23, 3389, 21, 20, 5900, 2222)
  3. **数据库与缓存服务** (3306, 5432, 6379, 27017, 1433, 1521, 9200, 9300, 11211, 8123)
  4. **消息队列与微服务组件** (5672, 15672, 9092, 2181, 8848, 8500, 2379)
  5. **云原生与网络基础协议** (2375, 2376, 6443, 9090, 53, 25, 465, 445)
- **端口状态卡片 (Port Status Card)**：
  - Header：端口号（如 `3306 / TCP`）、常用服务名称（`MySQL`）、状态 Badge（`🟢 OPEN` / `🔴 CLOSED` / `🟡 FILTERED`）。
  - Body：TCP 握手耗时（如 `15ms`）、服务详细用途解释、高危暴露风险警示标签（如 Redis 6379 未加密提示）。

### 1.3 底部：常用端口与服务协议百科字典 (Port Knowledge Dictionary)
- 包含 40+ 常用端口的中文说明、规范名称与安全注意事项。
- 点击字典中的任何端口卡片，自动将该端口添加到顶部探测框。

---

## 2. 探测技术原理 (Probe Strategy)

在纯前端浏览器环境中：
1. **HTTP / HTTPS 端口 (80, 443, 8080 等)**：利用带有 `AbortSignal.timeout` 的 `fetch(url, { mode: 'no-cors' })` 进行网络层时延与状态探针计算。
2. **TCP 通用端口**：结合 WebSocket / Img 加载试探及网络层握手算法计算开闭状态与 RTT 耗时。
3. **并发控制**：采用 Promise.all 批处理，带雷达扫描进度条动画。
